⚙️ 综合看板配置

可见板块

📦 结存板块

勾选的板块将结存：不可见、不可编辑、不计入徽标；取消勾选（含全不选）= 解封恢复。

🗂️ 新建看板

仅可选择你有权设置的部门（#206：超管/管理员全部；财务中心仅中心负责人/总经理/管理员；部门级仅本部门负责人）。
新建后看板立即归属所选部门（部门成员按架构授权可见），并出现在上方标签页（初始为空），可立即向其添加工作事项。工作空间 ID 与负责人不再在此填写（负责人默认为创建人，可稍后在看板管理中调整）。

🏗️ 架构管理

组织架构：中心 → 部门 → 常规小组；中心与部门均可设立专项小组（跨部门协作）。 小组配组长/组员，部门配部门长/部门骨干，中心配中心负责人/总经理/中心骨干。 同一人员可同时在多个节点任职（一人多岗、多组织任职）。

🔐 账号密码配置
